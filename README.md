# Employee Attrition Analysis

## 📌 Project Overview

This project focuses on analyzing employee attrition to understand workforce trends and identify factors related to employees leaving the company.

The project includes data cleaning, exploratory data analysis, business analysis using Python and SQL, and creating an interactive dashboard using Power BI.

> **Note:** The Machine Learning and Prediction part is not included yet and will be added in a future update.

## 🎯 Project Objectives

- Understand the structure of the employee dataset.
- Clean and prepare the data for analysis.
- Explore employee demographics and job-related information.
- Analyze employee satisfaction and performance.
- Identify patterns related to employee attrition.
- Answer business questions using SQL.
- Create an interactive Power BI dashboard.
- Generate useful insights to support HR decision-making.

## 🛠️ Tools & Technologies

- **Python**
  - Pandas
  - NumPy
  - Matplotlib
  - Seaborn
- **SQL**

## 📂 Project Workflow

### 1. Data Cleaning

The data cleaning process included:

- Checking the dataset structure.
- Reviewing data types.
- Checking for missing values.
- Checking for duplicated records.
- Removing unnecessary columns.
- Preparing the data for analysis.
- Making sure the dataset was ready for further analysis.

### 2. Exploratory Data Analysis — EDA

The exploratory analysis focused on understanding:

- Employee demographics.
- Department distribution.
- Job roles.
- Monthly income.
- Job satisfaction.
- Work-life balance.
- Job involvement.
- Years at the company.
- Overtime.
- Employee attrition.

Different visualizations were used to identify patterns and trends in the dataset.

### 3. Data Analysis

The analysis focused on answering business questions, such as:

- What is the overall employee attrition rate?
- Which departments have the highest attrition?
- Which job roles have the highest number of employees leaving?
- How does overtime relate to attrition?
- Does job satisfaction affect employee attrition?
- How does monthly income differ between employees?
- How do years at the company relate to attrition?
- Which employee groups may need more attention from HR?

### 4. SQL Analysis

SQL was used to query the employee dataset and answer business questions.

The SQL analysis included:

- Filtering employee records.
- Grouping employees by department and job role.
- Calculating employee counts.
- Analyzing attrition by different categories.
- Comparing employee satisfaction and income.
- Finding patterns in employee data.

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to present the main findings in a clear and easy-to-understand way.

The dashboard includes analysis of:

- Total employees.
- Employee attrition.
- Attrition rate.
- Department distribution.
- Job roles.
- Employee satisfaction.
- Monthly income.
- Overtime.
- Years at the company.

The dashboard helps users explore the data and understand the main employee attrition trends.
